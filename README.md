## 🌟 About The Project

**OmniPredict AI** brings **data, intelligence, prediction, and automation together in one platform**.

Instead of requiring users to switch between multiple tools for data preparation, analysis, machine learning, prediction, and automation, OmniPredict AI provides a **single intelligent ecosystem**.

Users can upload datasets, analyze their data, build predictive solutions, automate workflows, and communicate with an AI chatbot to receive real-time assistance and insights.

> 💡 **One Platform. Multiple AI Capabilities. Infinite Possibilities.**

---

## 🎯 Problem Statement

AI and data workflows often require multiple tools for:

* 📂 Data preparation
* 📊 Data analysis
* 🧹 Data cleaning
* 🧠 Model development
* 🔮 Prediction
* 🤖 AI assistance
* ⚙️ Automation

This makes the overall process **complex, time-consuming, and difficult to manage**.

### 💡 Our Solution

OmniPredict AI creates a **single intelligent ecosystem** where users can:

> **Upload → Analyze → Build → Predict → Explain → Automate**

# 🧠 AI Dataset Assistant

One of the core features of OmniPredict AI.

The **AI Dataset Assistant** helps users understand their datasets without requiring advanced data-science knowledge.

### It can help with:

* 📂 Dataset understanding
* 🧹 Data cleaning
* 🔍 Missing-value analysis
* 📊 Statistical analysis
* 📈 Data insights
* 🔗 Column relationships
* 🎯 Feature identification
* ⚠️ Data-quality detection
* 📝 Natural-language explanations

### Example

Instead of manually analyzing a dataset, a user can ask:

> **"What is the average price?"**

or

> **"Which column has the most missing values?"**

or

> **"Show me the most expensive listings."**

The AI Dataset Assistant analyzes the uploaded dataset and provides a meaningful response.

# 🔄 How It Works

| Step | Process                  | Description                                              |
| ---: | ------------------------ | -------------------------------------------------------- |
|   01 | 📥 **Input**             | Upload datasets, enter information, or ask the chatbot   |
|   02 | 🤖 **Dataset Assistant** | Understand, clean, and prepare the data                  |
|   03 | 💬 **Omni Copilot**      | Communicate with AI using natural language               |
|   04 | 🧠 **AI Engine**         | Apply ML, NLP, Vision, AutoML, forecasting, etc.         |
|   05 | 🧩 **Model Hub**         | Train, explain, and monitor models                       |
|   06 | 📊 **Output**            | Receive insights, predictions, explanations, and results |

# ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Aditya-ZOD/OmniPredict-AI.git
```

### 2️⃣ Navigate into the project

```bash
cd OmniPredict-AI
```

### 3️⃣ Create a virtual environment

```bash
python -m venv venv
```

### 4️⃣ Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the project

```bash
python app.py
```

Then open the local URL displayed by the application.
